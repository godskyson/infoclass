알고리즘 빌더

문제를 맞추면 숨겨진 자연어 알고리즘이 순서대로 채워집니다.

  • 1단계: 이벤트
    1단계 문제를 맞춰 잠금을 해제하세요
    오브젝트를 클릭하여 프로그램을 시작한다.
  • 2단계: 입력 받기
    2단계 문제를 맞춰 잠금을 해제하세요
    아이디와 비밀번호를 사용자에게 묻고 각 입력 변수에 저장한다.
  • 3단계: 1차 검증
    3단계 문제를 맞춰 잠금을 해제하세요
    입력한 아이디와 비밀번호가 기존 정보와 모두 일치하는지 확인한다.
  • 4단계: 2차 인증 번호
    4단계 문제를 맞춰 잠금을 해제하세요
    1000부터 9999 사이의 4자리 무작위 수를 생성해 인증번호로 정하고 수신 신호를 보낸다.
  • 5단계: 인증 대조
    5단계 문제를 맞춰 잠금을 해제하세요
    사용자가 입력한 번호가 생성된 인증번호와 일치하는지 비교한다.
  • 6단계: 결과 안내
    6단계 문제를 맞춰 잠금을 해제하세요
    인증 성공 시 로그인 완료를, 틀리면 "땡 틀렸어요."를 말한다.
